Restaurant Table Turnover Analysis – Excel Dashboard

Project Overview
This project analyzes restaurant sales and order data using Microsoft Excel to identify revenue trends and customer payment patterns.

Tools Used
- Microsoft Excel 2021
- Power Query
- Pivot Tables
- Charts and Slicers

Key Features
- Revenue analysis
- Order and customer analysis
- Average bill analysis
- Payment method revenue comparison
- Interactive dashboard with slicers

Skills Demonstrated
- Data Cleaning
- Data Analysis
- Data Visualization
- Business Reporting
